# A6 – Bracket Drawing

## The Assignment

The given assignment this week was to create a CAD model of the bracket made in A5, and to use that to create a drawing in the CAD software. 

## Parametric Modeling in SolidWorks

To begin, I added all of the global variables I would need from the bracket drawing. The variables are described in the comments area on the right so it is known what belongs to what. The variables are shown below.
